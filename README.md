# Prince Kumar — Full-Stack Portfolio

Full-stack developer portfolio for **Prince Kumar** (B.Tech ECE @ IIIT Bhagalpur '27). Built with a **React (Vite) + Tailwind CSS** frontend and a **Node.js + Express + MongoDB** backend REST API.

---

## 🚀 Repository Structure

```
.
├── client/          # React (Vite) + Tailwind CSS Frontend
│   ├── src/         # Components, Pages, Data, Styles
│   └── package.json
├── server/          # Node.js + Express + MongoDB API Backend
│   ├── routes/      # Contact, Projects, Stats Endpoints
│   ├── models/      # Mongoose Models
│   └── server.js
└── README.md
```

---

## ⚡ Quick Start

### 1. Backend Server (`server/`)
```bash
cd server
npm install
npm start
# Runs on http://localhost:5000
```

### 2. Frontend Application (`client/`)
```bash
cd client
npm install
npm run dev
# Runs on http://localhost:3000
```

## 🌟 Key Features

- **Responsive Modern UI**: Dark glassmorphism aesthetics built with Tailwind CSS, Lucide icons, and Google Fonts.
- **Main Project Focus**: Highlights **Vingo** ([https://vingo-r5xt.onrender.com](https://vingo-r5xt.onrender.com)) as the flagship full-stack system with Socket.IO real-time order tracking & OTP delivery verification.
- **Technical Case Studies**: Deep dives into problem statements, solution architectures, engineering tradeoffs, and results.
- **Interactive Resume Modal**: Built-in resume preview and 1-click download.
- **Backend API Integration**: Working `/api/contact` endpoint with MongoDB storage and fallback.
